**Historical baseline.** See the [5 November implementation and verification report](../2026-11-05/implementation-and-verification.md) and [current remediation checklist](../2026-11-05/ppb-remediation-checklist.md) for subsequent changes and remaining evidence.

Basis: supplied Version 2 / April 2023 PDF. Printed page numbers are the document footer numbers; PDF file page = printed page + 8. Section 3 uses 1.x numbering in the original; the matrix preserves that quirk. Some related clauses are grouped explicitly. Scope/context clauses are not scored as controls.

**Statuses:** Implemented control = a demonstrated technical component, not overall legal compliance. Partial = some components exist but the obligation is incomplete. Gap = a concrete missing/contradicted control. Evidence required = operational/documentary facts not established by source/tests. Scope = context only.
